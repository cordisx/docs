# Repository Guide

Read `.agents/rules/README.md` before changing this repository.

Read `.agents/docs/README.md` for the current portal, source ownership, and
maintenance entry points.

Read the organization [CSS ownership and maintenance rule](https://github.com/cordisx/cordisxmono/blob/main/.agents/rules/css.md)
before changing CSS, stylesheet-generating code, or a style-bearing DOM contract.

- Do not author CordisX product or protocol documentation here.
- Change source material in its owning repository.
- Keep only aggregation, navigation, presentation, and publication configuration here.
- Describe the current static portal and planned aggregation separately; a
  source registry entry does not prove that its content is fetched or rendered.
- Never fetch `.agents/rules` or private planning repositories.
